# OpenApp SDK

**Python** and **Rust** client libraries and the **OpenAPI** specification for building integrations with OpenApp.

| Directory | Contents |
|-----------|----------|
| `rust/` | Rust workspace (core, common, C bridge) |
| `python/` | Python package (`openapp-sdk` on PyPI) |
| `api-spec/` | OpenAPI definitions |
